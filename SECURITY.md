# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
The OpenTradeAI team takes security and execution integrity seriously. If you discover a potential vulnerability, please report it responsibly:

1. **Do not disclose publicly:** Please avoid opening public GitHub issues for sensitive security vulnerabilities.
2. **Contact Channel:** Reach out directly to the maintainer via Telegram at [@JanzebBlockdev](https://t.me/JanzebBlockdev) or through verified channels listed on the repository profile.
3. **Response Timeline:** We aim to acknowledge reports within 48 hours and provide a patch or mitigation strategy within 7 business days.
