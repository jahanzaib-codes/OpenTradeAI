# 📝 Changelog

All notable changes to **OpenTradeAI** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-11-11
### Added
- Continuous integration GitHub Actions workflow for Python 3.10 and 3.11 build matrices.
- Institutional open-source community standards: `CONTRIBUTING.md` and `SECURITY.md`.
- Structured version changelog.

## [1.0.0] - 2026-11-08
### Added
- Multi-Agent LLM Trading Terminal architecture powered by LangGraph.
- Specialized agents: Sentiment Analyst, Technical Screener, Risk Manager, Execution Router.
- FastAPI REST endpoints and interactive Swagger API documentation.
- Production containerized Dockerfile and docker-compose orchestration support.
